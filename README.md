# toDoList
No projeto da To-Do List, as tecnologias utilizadas são:
	•	HTML: responsável por estruturar a página, organizando os campos de entrada, botões e a lista de tarefas, formando a base visual do aplicativo.
	•	CSS: utilizado para estilizar os elementos, definindo cores, espaçamentos, fontes e tornando a interface mais agradável, responsiva e intuitiva para o usuário.
	•	JavaScript: implementa toda a lógica da aplicação, permitindo adicionar, marcar como concluídas e remover tarefas em tempo real, além de manipular dinamicamente o DOM para atualizar a lista conforme as interações do usuário.
